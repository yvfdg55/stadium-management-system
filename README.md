# نظام إدارة الملعب

تطبيق Flask عربي لإدارة ملعب، المسؤولين، العملاء، ومواعيد الحجوزات.

## النطاق الحالي

- تسجيل دخول مسؤول وصفحات عربية باتجاه RTL وتصميم متجاوب.
- إدارة العملاء: عرض وبحث وإضافة وتعديل وحذف، مع صفحة لكل عميل تعرض ملخصًا ماليًا وسجل جميع حجوزاته مرتبًا من الأحدث إلى الأقدم.
- تقويم شهري يعرض جميع أيام الشهر مع التنقل بين الأشهر.
- إنشاء حجز بالنقر على ساعة متاحة، مع اختيار العميل والتاريخ ووقت البداية وعدد الساعات وسعر الساعة والملاحظات.
- احتساب وقت النهاية والإجمالي تلقائيًا، والتحقق من صحة ساعات العمل.
- منع الحجوزات المتداخلة في التاريخ نفسه؛ الأوقات المجاورة دون تداخل مسموحة.
- تعديل الحجز وإلغاؤه؛ الإلغاء يحتفظ بسجل الحجز ويحرر الوقت لإعادة الحجز.
- تسجيل دفعات متعددة لكل حجز مع سجلها، واحتساب المدفوع والمتبقي وحالة السداد تلقائيًا.
- إدخال العربون أو المبلغ المدفوع مباشرة من نموذج إنشاء الحجز عند اختيار ساعة متاحة.
- حالة السداد «مدفوع بالكامل» عند اكتمال الإجمالي، و«عربون» قبل ذلك؛ لا يقبل النظام دفعة تتجاوز المتبقي.
- تقارير الحجوزات السارية لليوم والشهر الحالي والسنة الحالية، مع تقرير لفترة تاريخية مخصصة.
- تشمل التقارير عدد الحجوزات وقيمة الإجمالي والمدفوع والمتبقي وعدد الساعات؛ الحجوزات الملغاة مستبعدة.
- صفحة إعدادات لحفظ بيانات الملعب وسعر الساعة ومدة الحجز ونافذة التشغيل في قاعدة البيانات.
- تخصيص اللون الأساسي والثانوي ولون الخلفية من صفحة الإعدادات، وتطبيقها على صفحات التطبيق.
- الإعداد الافتراضي لدورة التشغيل 10:00 إلى 10:00 في اليوم التالي (24 ساعة)، ومدة الحجز الافتراضية ساعة.
- يبدأ تاريخ الحجز يوم الملعب عند وقت بداية التشغيل؛ ساعات ما بعد منتصف الليل تظل ضمن دورة تاريخ بدايتها.
- قاعدة بيانات SQLite تُنشأ تلقائيًا عند التشغيل.

لا تتضمن النسخة الحالية ردّ مبالغ أو بوابة دفع إلكترونية. مصطلح «عربون» هو حالة سداد عندما يكون المدفوع أقل من الإجمالي.

## التشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

ثم افتح: `http://127.0.0.1:5000/login`.
بعد تسجيل الدخول، شاشة التقويم والحجوزات على: `http://127.0.0.1:5000/admin/booking`.

يمكن تعديل إعدادات الملعب وساعات التشغيل من صفحة **الإعدادات** في لوحة الإدارة. ويُستخدم `HOURLY_RATE` كقيمة ابتدائية فقط عند تهيئة قاعدة بيانات جديدة. يتطلب إنشاء الحجز إضافة العميل أولًا.

## المسؤول الافتراضي

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

يُنشأ المستخدم تلقائيًا عند أول تشغيل، وتُحفظ كلمة المرور بصيغة hash داخل SQLite. غيّر بيانات الدخول الافتراضية قبل الاستخدام الفعلي.
