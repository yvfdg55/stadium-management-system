# نظام إدارة الملعب

نسخة أولية بسيطة لإدارة ملعب، تشمل تسجيل دخول المسؤول وإدارة العملاء.

## النطاق الحالي

- تطبيق Flask بسيط.
- قاعدة بيانات SQLite تُنشأ تلقائيًا عند التشغيل.
- جدول `admins` وجدول `clients` فقط.
- صفحة تسجيل دخول عربية باتجاه RTL وتصميم Mobile First.
- صفحة محمية بعد تسجيل الدخول.
- قائمة العملاء مع البحث بالاسم أو رقم الهاتف.
- إضافة العميل وتعديله وحذفه، مع الاسم ورقم الهاتف والملاحظات.
- شاشة مواعيد تعرض الأيام السبعة القادمة وساعات العمل فقط.
- إعدادات ساعات العمل وسعر الساعة عبر متغيرات البيئة.

لا توجد حاليًا وظيفة لإنشاء الحجوزات أو الدفع أو التقارير.

## التشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

ثم افتح: `http://127.0.0.1:5000/login`

شاشة المواعيد متاحة بعد تسجيل الدخول على: `http://127.0.0.1:5000/admin/booking`

يمكن ضبط العرض عبر `BOOKING_START_HOUR` و`BOOKING_END_HOUR` و`HOURLY_RATE` في ملف `.env`.

## Admin الافتراضي

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

يُنشأ المستخدم تلقائيًا عند أول تشغيل، وتُحفظ كلمة المرور بصيغة hash داخل SQLite.
